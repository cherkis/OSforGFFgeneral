Dimension Dependence

This document inventories where the spacetime dimension d=4d = 4d=4 (and spatial dimension d−1=3d-1 = 3d−1=3) enters the proofs. The project defines STDimension := 4 in Basic.lean changing this value would require updates to every file listed below as essential or spatial.

Classification

  • Essential (d=4): The mathematical formula is specific to d=4d = 4d=4. Generalizing requires deriving the analogous formula in dimension ddd.
  • Spatial (d=3): Uses the spatial dimension d−1=3d - 1 = 3d−1=3 explicitly, typically for integrability estimates.
  • Structural: References STDimension or SpaceTime but the proof works for any ddd without change (beyond updating the abbreviation).

Generalization Notes

To port the project to a different dimension ddd:

  1. Change STDimension in Basic.lean.
  2. Replace the Bessel K1K_1K1​ representation with the general Kd/2−1K_{d/2-1}Kd/2−1​ form.
  3. Update the heat kernel normalization (4πt)−d/2(4\pi t)^{-d/2}(4πt)−d/2.
  4. Update Plancherel scaling factors (2π)d(2\pi)^d(2π)d.
  5. Verify spatial integrability: decay rate must exceed d−1d-1d−1.
  6. Replace Fin.sum_univ_four with the appropriate Fin.sum_univ variant.
